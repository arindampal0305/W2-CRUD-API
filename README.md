# Task API

A simple in-memory REST API for managing tasks, built with Python and FastAPI.

## Features

- Create tasks
- Read all tasks
- Read a task by ID
- Update tasks
- Delete tasks
- Input validation
- HTTP error handling
- Automatic Swagger API documentation

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
